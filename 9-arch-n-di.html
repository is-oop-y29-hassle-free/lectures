5.1

Три времени жизни

Transient: служба с временем жизни transient создаётся при каждом запросе из контейнера служб.
A service with a transient lifetime is created each time it's requested from the service container.
Scoped: для веб-приложений время жизни scoped означает, что служба создаётся один раз на клиентский запрос (соединение).
For web applications, a scoped lifetime indicates that services are created once per client request (connection).
Singleton: службы-одиночки создаются при первом запросе; каждый последующий запрос получает тот же экземпляр.
Singleton lifetime services are created … the first time they're requested … Every subsequent request … uses the same instance.
Microsoft Learn, «Service lifetimes» (перевод)

scoped — «одиночка внутри единицы работы»: HTTP-запрос в ASP.NET Core, скоуп руками в консоли

Демо: одна служба, три регистрации

Captive dependency
